# §2 — REMEDIATION DESIGN

实现一个最小、明确的数据目录独占机制。

推荐设计：

```text
<datadir>/node.lock
```

启动节点时：

```text
attempt exclusive creation
```

要求：

- 使用 `O_CREATE | O_EXCL`
- 如果 lock 不存在：成功创建
- 如果 lock 已存在：拒绝启动
- 不得覆盖已有 lock
- 不得 truncate 已有 lock
- 不得在 lock 已存在时继续打开 blocks.dat

lock 内容只保存最小诊断信息，例如：

```text
pid=<process id>
started_at=<timestamp>
```

不得保存敏感信息。

# §3 — LOCK ERROR SEMANTICS

定义明确的、可测试的错误类型。

至少区分：

### A. DATADIR LOCKED

含义：

```text
data directory is already in use
```

用户看到的 CLI 错误必须明确说明：

- datadir 被另一个节点占用
- 当前节点没有启动
- 不要删除 blocks.dat
- 不要继续启动第二个实例

推荐用户级文案：

```text
Error: data directory is already in use by another node process.

Data directory:
<path>

Only one node process may use a data directory at a time.
```

---

### B. EXISTING DATA / REPLAY FAILURE

不要把：

```text
node.lock exists
```

和：

```text
blocks.dat replay failed
```

混成同一种错误。

二者必须保持语义独立。

# §4 — LOCK LIFECYCLE

正常启动：

```text
acquire node.lock
↓
initialize node
↓
open storage
↓
start runtime
```

必须保证：

**如果后续初始化失败，也不会留下一个本来不需要存在的 lock。**

正常 shutdown：

```text
stop runtime
↓
close storage
↓
release node.lock
```

lock release 必须在正确的 shutdown 生命周期中执行。

---

# §5 — CRASH / STALE LOCK POLICY

本阶段：

**禁止实现危险的自动 stale-lock 删除。**

特别禁止：

```text
lock exists
↓
PID not running
↓
自动删除 lock
↓
继续启动
```

本阶段只要求：

- 正常退出能够释放 lock
- 已存在 lock 时明确拒绝启动
- 异常残留 lock 不得被静默覆盖
- 为未来 stale-lock recovery 留出明确扩展点

如果实现需要平台相关 OS file locking 才能可靠满足要求，必须先报告设计差异，不得未经授权扩大范围。

# §6 — TESTS

新增测试必须覆盖至少：


### Test 2 — Second acquisition fails

```text

```

必须稳定失败，并识别为：

```text

```

---

### Test 3 — Existing lock is never overwritten

预先创建 lock：

```text
known content
```

第二次 acquisition：

必须失败。

验证原 lock 内容保持完全不变。

---

### Test 4 — Release allows reacquisition

```text
acquire
↓
release
↓
acquire
```

必须 PASS。

---

### Test 5 — Initialization failure releases lock

模拟 runtime initialization failure：

```text
acquire
↓
initialization fails
↓
lock released
↓
next startup can acquire
```

---

### Test 6 — Same datadir process-level protection

尽可能使用真实 node/runtime：

```text
Node A → datadir X → starts
Node B → datadir X → must fail
```

必须验证：

- B 不启动 RPC
- B 不启动 P2P listener
- B 不修改 blocks.dat
- B 返回明确 locked error
