最重要的**结构性发现**（本阶段的核心价值，比单个名字更重要）：

```text
可防御性悖论
─────────────────────────────────────────────
越「有语义」→ 越被同定位组织占用（人道/验证域全满）

结论：命名必须放弃「短促 + 强语义」路线，
      转向「较长 + 高显著性 + 弱语义负担」路线。
```

# 7. NAMING STRATEGY —— 6 个命名方向（FAMILY A–F）

| 家族 | 主题 | 约束 |
|---|---|---|
| **A — TRUST / TRUTH** | truth / trust / integrity / proof / credibility / honesty | 禁用平淡词 Trust / Truth / Proof / Verify / Verity，除非构成明显独特新造词 |
| **B — HUMAN / HUMANITY** | human / humanity / dignity / care / life / people / hope | 避免 HumanCoin / HopeCoin / CharityChain / HumanChain 类低质命名 |
| **C — PROOF / VERIFICATION** | proof / evidence / verification / witness / attestation / integrity | 追求「技术感 + 人文感」，而非纯企业 SaaS 感 |
| **D — NETWORK / CONNECTION** | connection / bridge / link / open / mesh / common / shared | 避免拥挤的 Nexus / Link / Bridge / Network / Chain，除非真正独特组合 |
| **E — ORIGINAL COINED WORD** | 完全原创：抽象造词 / 混构造词 / 短音造词 | 必须真实检索，不得凭「感觉可注册」放行 |
| **F — RARE-ROOT / LESS-COLONIZED**（本阶段新增） | 非拉丁 / 非希腊的稀有语根，或拉丁语法的独特变形 | 须评估文化挪用风险；须真实检索 |

> **本文档在规格给定的 A–E 之外新增 FAMILY F。** 理由：A–E 的实证结果（见 §10）显示前五个家族的可用空间已枯竭，
> 必须显式增设一个「稀有语根 / 独特变形」方向以覆盖剩余可行空间。

### 10.2 三个致命模式（可复用的命名认知）

**模式一 —— attest-/proof 词族在 Web3 已彻底饱和。**
`Attesta` / `Attestara` / `Attestia` / `Attesto` / `Pistis` / `Testari` / `Veracity` / `Probity`

**模式三 —— 短促造词（2 音节）被 Web3 项目优先抢占。**

# 12. SHORTLIST —— TOP 3

## 12.1 首选 —— `Probata`

```text
Probata Network / Probata Protocol / Probata Node
Probata Wallet  / Probata Explorer / Probata Proof / Probata Impact
中文：普罗巴塔
```

- **词源**：拉丁语 `probata`，`probare`（检验、证明、认可）的过去分词中性复数，
  义为「**已被验证 / 已被证明之物**」。同源词：probability、probity、probate、probation、approbation、proof。
- **为何最防御**：本轮 26 个候选中，**唯一完全没有 Web3 / 加密冲突的语义名**。
- **为何契合内核**：它本身就是「Public Proof」的词源形态，且为中性名词（无投机 / 赌博 / meme 联想）。
- **可扩展性**：7 种 `[BRAND] +` 组合全部自然，中文、英语、西语、意语均可发音。
- **残余风险（必须披露）**：
  1. `probatacorp.com`（美国 Probata Corporation，校准 / 计量，1978 年，A2LA ISO17025）
     → 在美国 **Class 009** 存在在先普通法商标风险；
  2. `probata` 在生物学中是分类学术语，可能稀释自然搜索；
  3. **本报告不构成任何法律清关结论。**
