# 0. EXECUTIVE RULES

本阶段必须严格遵守以下规则：

## 0.1 不允许拍脑袋命名

不得：

- 随机生成一个名字然后直接宣布采用；
- 因为名字“好听”就进入最终候选；
- 因为域名看起来可注册就认为品牌可用；
- 因为 Google 搜索没有结果就认为没有冲突；
- 因为 Crypto 项目已经停止运营就认为可以直接使用；
- 因为某个商标在其他国家注册就简单判断全球可用；
- 因为 ticker 看起来不错就倒推品牌；
- 因为 AI 自己认为名字高级就批准。

本阶段必须建立：

> **DISCOVER → SCREEN → ELIMINATE → SCORE → SHORTLIST → RECOMMEND**

完整流程。

# 7. NAMING STRATEGY

建立至少 6 个不同命名方向。

## FAMILY A — TRUST / TRUTH

围绕：

```text
truth
trust
integrity
proof
credibility
honesty
```

但禁止直接使用过于普通的：

```text
Trust
Truth
Proof
Verify
Verity
```

除非形成明显独特的新造词。

---

## FAMILY B — HUMAN / HUMANITY

围绕：

```text
human
humanity
dignity
care
life
people
hope
```

但避免：

```text
HumanCoin
HopeCoin
CharityChain
HumanChain
```

等低质量 Crypto 命名。

---

## FAMILY C — PROOF / VERIFICATION

围绕：

```text
proof
evidence
verification
witness
attestation
integrity
```

重点寻找：

> 技术感 + 人文感

而不是纯企业 SaaS 感。

---

## FAMILY D — NETWORK / CONNECTION

围绕：

```text
connection
bridge
link
open
mesh
common
shared
network
```

但避免直接使用高度拥挤的：

```text
Nexus
Link
Bridge
Network
Chain
```

除非形成真正独特的组合或新造词。

---

## FAMILY E — ORIGINAL COINED WORD

重点探索：

> 完全原创的品牌词。

例如：

```text

abstract linguistic construction
hybrid linguistic construction
invented word
short phonetic word
```
