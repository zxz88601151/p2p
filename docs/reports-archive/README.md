# docs/reports-archive — 历史报告归档区

本目录用于收纳**仓库根目录散落的阶段性/审计报告**，避免根目录持续膨胀。

## 归档批次

| 批次目录 | 归档日期 | 文件数 | 说明 |
|---|---:|---:|---|
| `2026-10-02-root/` | 2026-10-02 | 80 | 从仓库根目录迁入的未跟踪报告（79 × `.md` + 1 × `.json`），内容未做任何修改 |

## 说明

- **只移动、不删除**：所有文件仅改变路径，内容逐字节不变。
- **不含凭据**：归档前已扫描，无 token / 口令 / 私钥值（命中的 "token" 均为 "tokenomics" 等说明性文字）。
- **仅根级文件**：子目录（`docs/`、`docs/prompts/`、`release/`）下的未跟踪文件**未**被迁入，保持原位。
- **命名规则**：`<归档日期>-<来源位置>/`，便于追溯来源与批次。

## 后续建议

- 新增报告请直接写入本目录下的批次子目录，或 `docs/phases/`，不要再堆到仓库根。
- 若某份报告需要长期引用，可考虑提升为 `docs/` 下的正式文档并纳入 SPEC 索引。
